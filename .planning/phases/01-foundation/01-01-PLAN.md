## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vercel build runner ↔ package.json | Vercel reads `engines.node` and rejects unsupported formats (`>=22` produces `Found invalid Node.js Version` per RESEARCH.md Pitfall C / §9). |

| OS metadata ↔ committed files | `.DS_Store` files leak directory listings and have appeared in past commits per CLAUDE.md context. |

| T-CONFIG-02 | I (info disclosure) | `.DS_Store` files leak macOS directory metadata | mitigate | Append `.DS_Store` to `.gitignore` (Task 2) — `.DS_Store` already exists in `git status` per session context |
