<!-- Verbatim recruiter-test methodology — single source of truth from D-19. -->

5-second recruiter test protocol (D-19):
1. Recruiter is ONE non-engineer (the user picks; can be a friend / family / colleague).
2. Desktop runs FIRST (on the recruiter's own laptop, browser of their choice). Open https://www.tatibekov.com cold (no prior cache; fresh tab; do NOT log in to Google account if avoidable to reduce auto-fill weirdness).
3. Start a stopwatch the moment the page renders. Tell the recruiter: "Find Bakytbek's resume and his contact info. I'll time you."
4. Record:
   - Time-to-resume: seconds from page-render to the moment they CLICK the resume button (any of the resume surfaces: TopBar `↓ resume.pdf`, palette `download_resume`, sidebar recruiter card, AboutSocials CTA).
   - Time-to-contact: seconds from page-render to the moment they find an email/GitHub/LinkedIn anchor (sidebar contact.sh row, AboutSocials section, contact page link, palette `copy email` verb).
   - Path narrative: a one-sentence description of WHAT they clicked first ("clicked top-bar download immediately" vs "scrolled to about, then top-bar" vs "opened sidebar, clicked contact").
5. Repeat on 375px mobile (the recruiter's OWN phone — Safari iOS / Chrome Android — D-18 accepts the DevTools-emulation limitation for everything except the recruiter test itself, which by D-19 design happens on a real phone). Reload to `https://www.tatibekov.com` cold. Same protocol.
6. Pass = under 5s on BOTH metrics for BOTH devices (4 metrics total: desktop-resume, desktop-contact, mobile-resume, mobile-contact).
7. Memory carryover is an accepted limitation per D-19 (same person sees both devices; their second run benefits from learning the first).

Unfurl test protocol (Phase 5 SEO-03c carry):
1. Send `https://www.tatibekov.com` to a private Slack channel (DM to self is fine). Wait for Slack to fetch + render the unfurl. Screenshot the unfurl card.
2. Send `https://www.tatibekov.com` to a LinkedIn DM (DM to a willing contact, or self if LinkedIn allows self-DM). Wait for LinkedIn unfurl. Screenshot the card.
3. Expected: both unfurls render a branded OG image (the root opengraph-image.tsx from Phase 5 Plan 05-02), the title "Bakytbek Tatibekov — Sr. Software Engineer", and the description "Terminal-styled portfolio — engineering work, shipped apps, tech stack, and contact."
4. If the title is wrong or the OG image is missing/broken, that's a failure — likely metadataBase regression or OG-image rendering issue post-Phase 7 redeploy.
