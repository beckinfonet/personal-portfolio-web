# Phase 5 — UI Design Contract

> Visual and interaction contract for Phase 5 (SEO + Accessibility Polish). Generated by gsd-ui-researcher.
>
> Phase 5 is largely behavior/markup-driven (metadata files, JSON-LD, sitemap/robots, contrast verification, screen-reader-friendly easter eggs, prebuild placeholder grep). The design system itself was locked in Phase 2 and is NOT re-specified here. This contract documents only:
>
> 1. The new visual surfaces this phase introduces — **OG image card (1200×630), favicon `>_` glyph (32×32 + 180×180), AboutSocials inline contact-card, console signature ASCII art, view-source HTML comment**.
> 2. The cross-cutting visual/a11y contracts this phase locks — **focus-visible token, skip-link, contrast-corrected accent hues across the 4×2 matrix, reduced-motion belt-and-suspenders reset**.
> 3. The copywriting contract — **CTA, empty-state, error-state, destructive copy** the planner and executor must consume verbatim.
>
> All locked baseline tokens (palette, type scale, spacing scale, font) are referenced via the canonical sources (`app/globals.css` and `design_handoff_terminal_portfolio/README.md`).

### Contrast contract (A11Y-07) — Phase 5 LOCKS

**Matrix:** 4 hues × 2 themes × 7 routes = 56 cells, run via `@axe-core/playwright@^4.11.3` against `localhost:3000` with `localStorage["theme"]` and `localStorage["portfolio-accent"]` seeded by `page.addInitScript()` (RESEARCH Architecture Pattern 7). Failure threshold: any axe `serious`/`critical` `color-contrast` violation fails the build.

**Required minimums (WCAG 2.1 AA — D-23):**
- Body text (≥14px non-bold, ≥18.66px / 14pt non-bold legacy): **≥ 4.5:1**
- Large text (≥18pt = 24px non-bold OR ≥14pt = 18.66px bold): **≥ 3:1**
- UI component graphics (icons, focus rings, borders that convey state): **≥ 3:1**

**Predicted failure (D-22 / RESEARCH Pitfall 5):** amber-on-light = `oklch(0.5 0.16 60)` on `oklch(...)` light bg ≈ ~3.2:1 against body text. Remediation contract:
- Add to `app/globals.css` inside `[data-theme="light"]` scope, gated by hue if axe confirms:
  ```css
  [data-theme="light"][style*="--accent-hue: 75"] {
    --warn: oklch(0.42 0.18 75);  /* lower L, higher C — bumps contrast */
  }
  ```
  OR scope to specific UI roles (e.g. `.btn-warn`, prompt-line `$`, hex-hash) rather than global `--warn` if global flattens brand. **Planner audits first; remediates only what fails — preserves brand consistency with handoff palette.**

## Interaction & Motion Contract

### Reduced-motion (A11Y-03 / D-16, D-17)

**Belt-and-suspenders global reset** appended inside the existing `@media (prefers-reduced-motion: reduce) { ... }` block at `app/globals.css:152`:

```css
@media (prefers-reduced-motion: reduce) {
  /* NEW Phase 5 — universal reset (D-16) */
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }

  /* EXISTING — kept for documenting historical intent (D-17) */
  .cursor { animation: none; }
  .content-block { animation: none; }
  .breadcrumb-hint { transition: none; opacity: 1; }
  .drawer-sheet[data-state="open"],
  .drawer-sheet[data-state="closed"] { animation: none; }
  .drawer-backdrop { transition: none; }
  [cmdk-dialog] { animation: none; }
}
```

**Critical:** `0.01ms` not `0ms` (RESEARCH Pitfall 7 — some browsers treat `0` as falsy, skip override).

**Cursor stays visible (D-18):** the existing `.cursor { animation: none; }` keeps the 8×14px accent block rendered without flicker — friendly behavior for vestibular triggers.

**Boot fade (D-19) = the existing `slideIn` on `.content-block`** (Phase 2 SHELL-08; 0.25s play-once). Already covered.

**OS verification:** Tester enables Reduce Motion in macOS System Settings → Accessibility → Display, reloads each route, observes no `slideIn`, no cursor blink, no drawer slide. (Manual gate per 05-VALIDATION.md §Manual-Only Verifications.)

### Focus-visible (A11Y-02) — locked Phase 2; reaffirmed Phase 5

```css
*:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}
*:focus:not(:focus-visible) { outline: none; }
```

**Phase 5 contrast contract:** the focus outline must hit ≥3:1 against every background it lands on across the 4×2 hue/theme matrix. axe-core `color-contrast` rule covers this; remediation per D-22.

### Skip-link (A11Y-01) — locked Phase 2; reaffirmed Phase 5

```css
.skip-link {
  position: absolute; top: -100%; left: 16px;
  padding: 8px 16px;
  background: var(--panel-hi); color: var(--accent);
  border: 2px solid var(--accent); border-radius: 4px;
  font-size: 13px; text-decoration: none; z-index: 200;
}
.skip-link:focus { top: 16px; }
```

Reveals on `:focus` at top of `<body>`. Phase 5 axe matrix verifies the revealed state contrast.

Themed equivalently per `.planning/codebase/CONCERNS.md` (CSP nonce work deferred to a future security-audit pass; Phase 1 D-15 deferral remains in effect). **XSS gotcha mitigated** by mandatory `JSON.stringify(...).replace(/</g, '\\u003c')` in `lib/json-ld.ts` — without it, an attacker-controlled `PROFILE` field could close the `<script>` tag early. PROFILE is dev-controlled today, but the discipline ships now (Phase 6 adds `description` and `image` fields).
