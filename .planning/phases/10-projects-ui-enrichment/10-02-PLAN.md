| RSC server (`projects/page.tsx`) → client island (`project-row.tsx`) | `getRepoStats()` and `GITHUB_TOKEN` live server-side; only plain serializable props (`StripModel` / `PanelModel` / strings) cross into the client island. |

| Visitor → external CTA links (`View on GitHub`, `Visit project`) | Outbound navigation to third-party URLs from project data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-03 | Information Disclosure | `project-row.tsx` import graph | mitigate | The client island must NEVER import `lib/github.ts` — that module imports `node:fs/promises` and reads `GITHUB_TOKEN`; pulling it into a `"use client"` component would leak the token into the client bundle and break the build. The island imports only `@/lib/project-stats` (pure, Plan 01 verified import-clean) and primitive components. Acceptance criteria grep enforces zero `node:` / `lib/github` imports in `project-row.tsx`. |
| T-10-04 | Tampering | `View on GitHub →` / `Visit project →` CTAs | mitigate | Both CTAs reuse the `ExternalLink` primitive, which bakes in `target="_blank" rel="noopener noreferrer"` (SEO-05) — prevents reverse-tabnabbing. No hand-rolled `<a>`. |
| T-10-05 | Tampering / Injection | GitHub language-name strings in strip/panel | mitigate | Language names and counts are rendered as JSX text nodes — React auto-escapes. No `dangerouslySetInnerHTML` anywhere in the strip or panel markup. |
| T-10-06 | Tampering | `javascript:` URL in `repoUrls[0]` / `project.link` | accept | `repoUrls` and `link` are curated portfolio data in `lib/portfolio-data.ts`, all `https://github.com/...` / HTTPS; the INFRA-05 prebuild grep guards placeholders.
